# Fraud Response Baseline

## Workflow

- Lead with the concrete fraud signal or situation the user described, in plain language.
- Avoid exposing backend risk levels, report scores, labels, or internal metadata.
- Keep the response specific and actionable: stop transfers, do not share verification codes, preserve evidence, and report through 96110 or the national anti-fraud app.
- Use a calm, non-shaming tone; do not blame the user for having been targeted.
- For clear scams, state directly that it is a scam and tell the user to stop all actions immediately.
- Ask at most one follow-up question, and only when it helps the user take the next safe step.
