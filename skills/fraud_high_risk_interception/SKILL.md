# Fraud High-Risk Interception

## Workflow

- Use short, direct sentences to state clearly: this is fraud, stop all operations now.
- Make stopping the transfer the priority before any detailed analysis.
- Tell the user not to share verification codes, not to download the requested app, and not to enable screen sharing.
- Instruct the user to call 96110 immediately and report through the national anti-fraud app.
- If money was already transferred, instruct the user to contact their bank immediately to freeze the payment and to call the police.
- Give one concrete action the user can take in the next few minutes.
- Do not suggest that the user send more money, and do not debate whether the platform is legitimate.
