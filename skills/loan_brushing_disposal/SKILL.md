# Loan Brushing Disposal

## Workflow

- State that legitimate loans never require fees, deposits, or unfreezing payments before disbursement.
- For brushing/rebate scams, point out that any scheme requiring an upfront payment to "unlock" earnings is a scam.
- Tell the user to stop any further "make-up" payments and not to share verification codes or card details.
- Remind the user that "credit repair" does not exist — credit records are only managed through official channels.
- Instruct the user to preserve chat logs, transfer receipts, and app details, then call 96110 and request a bank freeze.
